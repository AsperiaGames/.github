# AsperiaGames

AsperiaGames is focused on building interactive game experiences and the supporting GitHub standards around them.

## Repository Breakdown

### [GameCenter](https://github.com/AsperiaGames/GameCenter)
A React-based micro frontend game hub that is designed to run standalone or plug into a larger site. It provides the shared foundation for browser-based games, including modular game loading, reusable game resources, and deployment-ready configuration.

### [.github](https://github.com/AsperiaGames/.github)
The organization-wide repository for shared GitHub configuration and profile content, including this overview of what the organization is building.
