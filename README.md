# AsperiaGames

AsperiaGames is focused on building interactive game experiences and the supporting GitHub standards around them.

## Repository Breakdown

### [GameCenter](https://github.com/AsperiaGames/GameCenter)
A React-based micro frontend game hub that is designed to run standalone or plug into a larger site. It provides the shared foundation for browser-based games, including modular game loading, reusable game resources, and deployment-ready configuration.

### [arcade-api](https://github.com/AsperiaGames/arcade-api)
A Go backend service for supporting game-related API functionality across the organization’s projects.

### [pokegallery](https://github.com/AsperiaGames/pokegallery)
A JavaScript project that allows users to browse Pokémon data in list and detail views.

### [Python_Pong](https://github.com/AsperiaGames/Python_Pong)
A classic Pong game built with Python, recreating the two-player paddle-and-ball gameplay experience.

### [QuantumDefense](https://github.com/AsperiaGames/QuantumDefense)
A Swift game project focused on the QuantumDefense experience.

### [Python_Snake](https://github.com/AsperiaGames/Python_Snake)
A Python implementation of Snake.

### [Pokemon-Game](https://github.com/AsperiaGames/Pokemon-Game)
A C# remake of a Pokémon-themed game.

### [signal-hunt](https://github.com/AsperiaGames/signal-hunt)
A Lua game project centered on the signal-hunt experience.

### [Concepts](https://github.com/AsperiaGames/Concepts)
A repository for gameplay, feature, or product concepts.

### [coin-run](https://github.com/AsperiaGames/coin-run)
A Lua game project focused on coin-run gameplay.
